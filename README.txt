X Technology Invoice Studio Android wrapper (V8.58)

1. Install Android Studio.
2. Open this folder as a project (File > Open).
3. Wait for Gradle sync.
4. Connect Android phone or choose an emulator.
5. Build > Build Bundle(s) / APK(s) > Build APK(s).
6. The APK is usually under app/build/outputs/apk/debug/app-debug.apk.

This is a WebView wrapper around your supplied V8.58 HTML file. App data is stored using browser local storage within the app. Keep using the HTML system's JSON Backup / Restore feature for backups.

If Android Studio asks to upgrade Gradle or SDK, accept the recommended compatible upgrade.
